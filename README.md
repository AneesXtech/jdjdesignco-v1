# JDJ Design Co. — Hardware Design, Manufacturing & Packaging

Official website for **JDJ Design Co.** Designed in Spokane, built in Shenzhen.

## Overview
- Single-page responsive website
- High-performance vanilla HTML, CSS, and JavaScript
- Interactive hardware showcase and scroll animations
- Ready for zero-config deployment on [Vercel](https://vercel.com/)

## Deploying to Vercel
1. Import this repository into [Vercel](https://vercel.com/new).
2. Framework Preset: **Other** (Static HTML).
3. Root Directory: `./`
4. Click **Deploy**.
